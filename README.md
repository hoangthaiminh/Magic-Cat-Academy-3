# Magic Cat Academy 3 — Offline Archive

---

## Overview

This repository is an offline archival copy of **Magic Cat Academy 3**, a Google Doodle created by **Google** for Halloween 2024.

The game files were downloaded from the original web version and preserved by **Lugament_Remix** for archival and offline use.

## Purpose

This project exists solely to preserve and play the Doodle offline after its original web availability.

The original game content, gameplay, assets, and core functionality have been retained. Only minor changes required for offline preservation have been made.

## Modifications

The archived version includes:

- Removal of the original sharing functionality, as it is unnecessary for offline use.
- Local organization of required files and resources.
- Minification of CSS and JavaScript to reduce file size while preserving functionality.
- Addition of a simple English/Vietnamese language selector that controls the `hl` URL parameter and reloads the page accordingly.

No gameplay mechanics or original game content were intentionally changed.
